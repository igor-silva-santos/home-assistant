## 🚀 Visão Geral do Dashboard

Este projeto entrega um ecossistema Lovelace completo, tablet-first e altamente responsivo:

- **🏠 Home**: Orbe de lançamentos, tarefas e clima.
- **🏢 Cômodos**: Controle granular por ambiente com grid inteligente.
- **⚡ Energia**: Métricas de consumo real via ApexCharts.
- **🤖 Automações**: Painel de gerenciamento de rotinas.
- **🔒 Segurança**: Câmeras ao vivo e detecção de objetos por IA (Frigate).

## 🛠️ Instalação em 5 Passos

1. Clone o projeto para o seu servidor HA.
2. Execute o script de instalação: `bash scripts/setup.sh`.
3. Instale os custom cards via HACS (Mushroom, ApexCharts, Card Mod).
4. Configure os helpers e reinicie o HA.
5. Ative o tema **futuristic_dark** no seu perfil.
